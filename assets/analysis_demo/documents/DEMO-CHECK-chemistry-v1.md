# 虚构质量复核检查规程 v1.0

完全虚构的教学规程，仅适用于 DEMO-LINE-A 的 DEMO-A 钢种 review 阶段。依据 DEMO-RULE-A-REVIEW-v1 确认碳、硅或锰成分低于下限或高于上限时，仅进行下列人工检查：核对该炉次成分报告的样本编号、检测时间与炉次关联。核对钢种、复核阶段和当前使用的成分标准版本。将成分偏差事实及原始报告提交质量复核员人工确认。本条不规定设备调节、加料、升降温或 PLC 执行动作。
