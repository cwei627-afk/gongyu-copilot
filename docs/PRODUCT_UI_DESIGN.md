# 统一产品入口（Stage F）

用户打开 `http://127.0.0.1:18095`，只输入自然语言。没有功能选择器；示例按钮只填入问题，不决定执行路径。中文卡片展示结论、关键事实、分析、建议下一步、来源和人工确认，技术详情默认折叠。

## 实际实现

- React、TypeScript、Vite，无额外UI组件框架；构建文件由本机独立FastAPI进程托管，开发时可用Vite代理。
- 浏览器只调用同源`/api/copilot/*`，不访问Dify、不持有服务密钥、不存localStorage。无Markdown/HTML模型输出渲染；文本由React转义。
- Gateway使用固定服务地址调用原C/D/E1及两套扩容知识Published API。所有结果通过确定性Presenter转换，不显示模型自由回答或私有推理。
- Router先拒绝写操作/来源绕过，再解析明确对象和有限时间条件，高置信规则路由；仍不明确时可用闭合Enum的Dify分类节点，低置信或非法结构澄清。分类无实体生成或业务回答权限。
- 六类意图：企业受控知识、公开行业参考、实时系统查询、异常分析、澄清、不支持。企业制度问题不降级到公开常识。

## 交互与诚实状态

等待期间只显示“正在处理请求”，没有假的思考动画或预设业务阶段。完成后仅根据已验证事实和内部执行记录显示实际处理步骤；不声称核查了未调用的系统。页面连接提示表示Gateway与查询源可达，不代表所有外部模型始终可用。

来源卡片分开显示MES/ERP/WMS、企业受控资料和公开行业参考。文档可展开名称、版本、有效日期、章节、范围、可靠页码及公开URL；没有可靠页码明确说明。API provenance及Citation ID只在技术详情白名单中显示。

短期追问仅使用服务端签发的5分钟实体引用，下一次请求重新查源系统。没有事实缓存、多轮模型记忆或无限历史复用；页面刷新或服务重启后应重新给明确对象。

## 失败表达

| 内部结果 | 主界面 | 后续行为 |
|---|---|---|
| 对象不存在 | 未找到对应生产对象 | 停止推断，建议核对编号 |
| 缺项/过期/关联冲突 | 当前数据无法用于确认结论 | 不补值、不当作工艺异常 |
| 500/连接/timeout/结构校验失败 | 系统暂时无法完成查询 | 事实未知，不变成无证据或正常 |
| 企业证据不足 | 当前企业资料不足，无法确认答案 | 不转为模型常识回答 |
| 有参数偏差、无SOP | 已确认参数偏差，规程依据不足 | 可说明MES事实，不给确定性处置 |
| 缺少或多个对象 | 还需要补充查询条件 | 不猜炉次、订单、批次 |
| 写操作/提示注入 | 本系统仅提供只读辅助 | 不调用业务能力 |

## 演示数据

页面“演示数据说明”从Mock源摘要取得时间范围、400炉次、100订单、200批次和示例编号。知识规模来自受控资产：30现行+3非现行内部文档、4公开摘要。所有业务数据和内部规程虚构；公开摘要单独标记，不代表企业正式标准。

列表默认10、最多20，支持今天/昨天/本周/指定日期/有限日期区间/最近N炉和已有源状态过滤。历史待复核标记不代表当前工艺判定。大范围导出、SQL、写接口均不支持。

## 产品边界

本机只读PoC，无生产鉴权、多用户权限、审批平台、设备控制、复杂会话、生产可用性或性能承诺。页面优化不改变A/B/C/D/E1核心门禁。任意自然语言问题仍可能因未评审表达或证据不足而拒答，不能称为开放式制造业问答。

桌面优先（1440×900等），移动端仅基础响应式。实际页面、布局、错误与来源验证证据见`audit_artifacts/STAGE_F_VALIDATION.md`。
